Welcome to Season 2! We kick off with JavaScript fundamentals and learn how to make web pages interactive.

## Why JavaScript?

JavaScript is the programming language of the web. It runs in browsers and enables dynamic, interactive web experiences.

## Topics Covered

- **JavaScript Fundamentals**: Variables, data types, functions, and control flow
- **ES6+ Features**: Modern JavaScript syntax including arrow functions, destructuring, and template literals
- **DOM Manipulation**: Selecting elements, modifying content, and handling events
- **Event Listeners**: Responding to user interactions
- **Common Patterns**: Best practices for writing maintainable JavaScript

## Key Concepts

### Variables and Data Types

Understanding `let`, `const`, and `var`, plus the difference between primitive and reference types.

### Functions

Function declarations, expressions, arrow functions, and when to use each.

### DOM Selection

Using `querySelector`, `querySelectorAll`, and other methods to interact with page elements.

## Practical Examples

We build interactive features including:
- A dynamic counter with increment/decrement buttons
- A simple form validator
- An interactive image gallery

## Event Handling

Understanding event propagation, event delegation, and how to handle common user interactions like clicks, form submissions, and keyboard events.
